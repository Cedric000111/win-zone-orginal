🔐 Custom Match Security Flow

  1. Choose your amount.
  2. Create or find an offer.
  3. WIN ZONE checks player eligibility and available balance.
  4. Both players agree to the same final stake.
  5. The backend reserves the required funds.
  6. Only then is the private match room created.
  7. The match code is generated by the secure backend.
